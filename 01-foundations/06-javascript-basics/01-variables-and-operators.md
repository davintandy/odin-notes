# Variables and Operators

## Introduction to JavaScript

**JavaScript (JS)** is a programming language used to add interactivity and dynamic behavior to websites.

Together, HTML, CSS, and JavaScript form the three core technologies of frontend web development.

| **Technology** | **Responsibility** |
| --- | --- |
| HTML | Defines webpage structure and content |
| CSS | Controls visual appearance and layout |
| JavaScript | Adds interactivity and dynamic behavior |

Examples of what JavaScript can do:

- Respond to user interactions, such as button clicks.
- Update webpage content dynamically.
- Perform calculations.
- Validate form input.
- Create animations and interactive features.

JavaScript is also used outside web browsers, including server-side development with environment such as Node.js.

## Running JavaScript Code

During the Foundations course, JavaScript is primarily executed through the browser.

There are two common ways to include JavaScript in an HTML document.

### Inline JavaScript

You can write JavaScript directly inside a `<script>` element.

```html
<!DOCTYP html>
<html lang="en">
<head>
	<meta charset="UTF-8">
	<title>JavaScript Practice</title>
</head>
<body>
	<script>
		console.log("Hello, World!");
	</script>
</body>
</html>
```

### External JavaScript

For larger projects, JavaScript is usually stored in a separate `.js` file.

HTML:

```html
<script src="javascript.js"></script>
```

JavaScript (`javascript.js`):

```jsx
console.log("Hello, World!");
```

This approach separates JavaScript from HTML, making the project easier to organize and maintain.

### Using `console.log()`

The `console.log()` method displays information in the browser’s developer console.

```jsx
console.log("Hello, World!");
console.log(10 + 20);
console.log("Learning JavaScript");
```

To view the output:

1. Open your HTML file in browser.
2. Right-click the webpage and select **Inspect**.
3. Open the **Console** tab.
4. Find the output generated by `console.log()`.

The console is useful for testing expressions, checking variable values, and debugging JavaScript.

## Variables

A **variable** is a named storage location used to hold data that a program can access and work with.

Think of a variable as a labeled container that holds a value.

```jsx
let firstName = "John";
let age = 25;

console.log(firstName);
console.log(age);
```

Output:

```
John
25
```

Variables allow you to reuse information without repeatedly writing the same values.

### Declaring and Initializing Variables

There are two important terms:

- **Declaration**: Creating a variable using a declaration keyword.
- **Initialization**: Assigning its initial value.

You can declare and initialize a variable in one statement:

```jsx
let message = "Hello!";
```

You can also separate the two operations:

```jsx
let message;

message = "Hello!";
```

Here, `message` is declared first and initialized afterward.

### Reassigning Variables

Variables declared using `let` can be reassigned.

```jsx
let age = 20;

console.log(age); // 20

age = 25;

console.log(age); // 25
```

You do not need to write `let` again when reassigning an existing variable.

Writing `let` again with the same variable name in the same scope causes a syntax error.

## `let`, `const`, and `var`

JavaScript provides three keywords for declaring variables: `let`, `const`, and `var`.

| **Keyword** | **Can be reassigned?** | **Recommended usage** |
| --- | --- | --- |
| `let` | Yes | Values that need to change |
| `const` | No | Values that should not be reassigned |
| `var` | Yes | Legacy JavaScript code |

### `let`

Use `let` when a variable’s value needs to change.

```jsx
let score = 50;

score = 75;

console.log(score); // 75
```

### `const`

Use `const` when a variable should not be reassigned.

```jsx
const pi = 3.14159;

console.log(pi);
```

Attempting to reassign it produces an error.

```jsx
const pi = 3.14159;

pi = 3.14; // TypeError
```

A `const` variable must be initialized when declared.

```jsx
const name = "John"; // Valid

const name; // SyntaxError
```

**Important**: `const` prevents reassignment of the variable binding. It does not make objects or arrays deeply immutable; their contents can still be modified.

### `var`

`var` is the original way to declare variables in JavaScript.

```jsx
var name = "John";

name = "David";
```

Although it still works, `var` has different scoping and redeclaration behavior compared with `let` and `const`.

Modern JavaScript generally prefers `let` and `const`.

### Best Practice

- Use `const` by default when a variable does not need reassignment.
- Use `let` when it's value needs to change.
- Avoid `var` in modern JavaScript unless you are working with older code.

## Variable Naming Conventions

Choosing meaningful variable names makes code easier to understand, maintain, and debug.

### Naming Rules

JavaScript variable names must follow certain rules:

1. Names can contain letters, digits, underscores (`_`), and dollar signs (`$`).
2. Names cannot begin with a digit.
3. Names cannot contain spaces or hyphens.
4. Names are case-sensitive.
5. Reserved keywords, such as `let`, `class`, and `return`, cannot be used as variable names.

Examples:

```jsx
// Valid
let firstName = "John";
let userAge = 25;
let test123 = true;
let _count = 10;
let $price = 100;

// Invalid
let 1name = "John";
let first-name = "John";
let user age = 25;
```

### Camel Case

JavaScript commonly uses **camelCase** for variable names.

In camelCase:

- The first word starts with a lowercase letter.
- Each subsequent word starts with an uppercase letter.
- Words are joined without spaces.

Examples:

```jsx
let firstName = "John";
let lastName = "Doe";
let currentUserName = "David";
let totalShoppingPrice = 250;
```

### Naming Best Practices

- Use descriptive names that explain what the variable stores.
- Prefer `currentUser` over vague names such as `data` or `value`.
- Avoid unnecessary abbreviations.
- Use consistent terminology throughout the project.
- Prefer English names for readability and collaboration.

### Uppercase Constants

Constants representing fixed values known before execution are sometimes written using uppercase letters and underscores.

```jsx
const COLOR_RED = "#FF0000";
const MAX_USERS = 100;
const PI = 3.14159;
```

This convention helps distinguish fixed configuration values from ordinary variables.

Constants calculated during program execution generally use camelCase:

```jsx
const pageLoadTime = 2500;
const totalPrice = 150000;
```

## JavaScript Numbers

JavaScript uses the `Number` data type to represent ordinary numeric values, including integers and decimal numbers.

### Integers

Integers are whole numbers without fractional parts.

```jsx
let age = 25;
let temperature = -5;
let quantity = 100;
```

### Floating-Point Numbers

Floating-point numbers contain decimal values.

```jsx
let price = 19.99;
let percentage = 0.75;
let average = 87.567;
```

Both integers and floating-point numbers belong to the same JavaScript `Number` type.

```jsx
console.log(typeof 25); // "number"
console.log(typeof 19.99); // "number"
```

JavaScript also has a `BigInt` type for every large integers.

## Arithmetic Operators

Arithmetic operator perform mathematical calculations.

### Basic Arithmetic Operators

| **Operator** | **Name** | **Example** | **Result** |
| --- | --- | --- | --- |
| `+` | Addition | `10 + 5` | `15` |
| `-` | Subtraction | `10 - 5` | `5` |
| `*` | Multiplication | `10 * 5` | `50` |
| `/` | Division | `10 / 5` | `2` |
| `%` | Remainder | `10 % 3` | `1` |
| `**` | Exponentiation | `2 ** 3` | `8` |

### Addition

```jsx
let result = 10 + 5;

console.log(result); // 15
```

### Subtraction

```jsx
let result = 10 - 5;

console.log(result); //5
```

### Multiplication

```jsx
let result = 10 * 5;

console.log(result); / 50
```

### Division

```jsx
let result = 10 / 3;

console.log(result); // 3.33334
```

JavaScript division can produce decimal results.

### Remainder (`%`)

The remainder operator returns what remains after division.

```jsx
console.log(10 % 3); // 1
```

The remainder operator is useful for checking whether a number is even or odd.

- Even numbers produce a remainder of `0` when divided by `2`.
- Odd numbers produce a remainder of `1` when divided by `2`.

### Exponentiation (`**`)

The exponentiation operator raises a number to a specified power.

```jsx
console.log(2 ** 3); // 8
```

It can also be used to calculate square roots:

```jsx
console.log(8 ** (1 / 3)); // 2
```

## Operator Precedence

**Operator precedence** determines the order in which JavaScript evaluates operators within an expression.

JavaScript follows the familiar mathematical order of operations.

### General Order

| **Priority** | **Operation** | **Operators** |
| --- | --- | --- |
| 1 | Parentheses | `()` |
| 2 | Exponentiation | `**` |
| 3 | Multiplication and division | `*` / `%`  |
| 4 | Addition and subtraction | `+` / `-` |

Operators at the same precedence level generally evaluate from left to right, except exponentiation, which groups from right to left.

### Example Without Parentheses

```jsx
console.log(5 + 10 * 2); // 25
```

JavaScript performs multiplication first.

### Example With Parentheses

```jsx
console.log((5 + 10) * 2); // 30
```

Parentheses change the evaluation order.

**Best practice:** Use parentheses when an expression is complicated or when you want to make the intended calculation order clearer.

## String and Concatenation

A **string** is a data type used to represent text.

Strings are written inside quotation marks.

```jsx
let firstName = "John";
let lastName = "Doe";
```

JavaScript supports single quotes, double quotes, and template literals.

```jsx
let name = 'John';
let city = "Surabaya";
let message = `Hello!`;
```

### String Concatenation

**Concatenation** means joining strings together.

The `+` operator can combine strings.

```jsx
let firstName = "John";
let lastName = "Doe";

let fullName = firstName + " " + lastName;

console.log(fullName); // John Doe
```

### Combining Strings and Numbers

When the binary `+` operator encounters a string operand, JavaScript performs string concatenation rather than ordinary numeric addition.

```jsx
console.log("Hello " + "World"); // Hello World
console.log("Age: " + 25); // Age: 25
console.log("10" + 5); // "105"
```

The last example produces `"105"` because the number `5` is converted to a string.

### Important: Evaluation Order Matters

```jsx
console.log(2 + 2 + "1"); // "41"
console.log("1" + 2 + 2); // "122"
```

Explanation:

- `2 + 2 + "1"`: JavaScript calculates `2 + 2` first, then concatenates `"1"`.
- `"1" + 2 + 2`: JavaScript starts with a string, so the following additions concatenate strings.

The `+` operator is special because it can perform either numeric addition or string concatenation.

## Converting Strings to Numbers

Sometimes numeric values are stored as strings, particularly when retrieving values from HTML form inputs.

For example:

```jsx
let apples = "2";
let oranges = "3";

console.log(apples + oranges); // "23"
```

The result is `"23"` rather than `5` because both values are strings.

### Using `Number()`

The `Number()` function converts a value into a number when possible.

```jsx
let apples = "2";
let oranges = "3";

let total = Number(apples) + Number(oranges); // 5
```

### Using Unary Plus (`+`)

The unary plus operator can also convert a value into a number.

```jsx
let age = "25";

console.log(+age); // 25
```

### Invalid Conversions

If a string cannot be converted into a valid number, JavaScript returns `NaN` (Not-a-Number).

```jsx
let result = Number("Hello");

console.log(result); // NaN
```

You can check whether a value is `NaN` using:

```jsx
console.log(Number.isNaN(result)); // true
```

## Assignment Operators

Assignment operators assign values to variables or modify their existing values.

### Basic Assignment (`=`)

The `=` operator assigns the value on the right to the variable on the left.

```jsx
let age = 25;

age = 30;

console.log(age); // 30
```

It is important to distinguish assignment from comparison:

- `=` assigns a value.
- `===` compares values and types.

### Compound Assignment Operators

Compound assignment operators combine an arithmetic operation with assignment.

| **Operator** | **Meaning** | **Equivalent** |
| --- | --- | --- |
| `+=` | Addition assignment | `x = x + value` |
| `-=` | Subtraction assignment | `x = x - value` |
| `*=` | Multiplication assignment | `x = x * value` |
| `/=` | Division assignment | `x = x / value` |
| `%=` | Remainder assignment | `x = x % value` |
| `**=` | Exponentiation assignment | `x = x ** value` |

### Examples

```jsx
let number = 10;

number += 5;
console.log(number); // 15

number -= 3;
console.log(number); // 12

number *= 2;
console.log(number); // 24

number /= 4;
console.log(number); // 6
```

These operators make code shorter and reduce repetition.

## Increment and Decrement Operators

Increment and decrement operators increase or decrease a variable by one.

### Increment (`++`)

Increases a variable by `1`.

```jsx
let counter = 5;

counter++;

console.log(counter); // 6
```

Equivalent to:

```jsx
counter = counter + 1;
```

### Decrement (`--`)

Decreases a variable by `1`.

```jsx
let counter = 5;

counter--;

console.log(counter); // 4
```

Equivalent to:

```jsx
counter = counter - 1;
```

### Prefix vs. Postfix

The operators can be placed before or after a variable.

| **Form** | **Example** | **Returned value** |
| --- | --- | --- |
| Prefix | `++counter` | New value after incrementing |
| Postfix | `counter++` | Original value before incrementing |

Example using prefix:

```jsx
let counter = 1;

let result = ++counter;

console.log(result); // 2
console.log(counter); // 2
```

Example using postfix:

```jsx
let counter = 1;

let result = counter++;

console.log(result); // 1
console.log(counter); // 2
```

Both forms increase the variable by one. The difference is the value returned when the expression is evaluated.

**Best practice**: Avoid placing increment or decrement operators inside complicated expressions. Keeping one action per line makes code easier to understand.

## Comparison Operators

Comparison operators compare two values and return a Boolean result: `true` or `false`.

| **Operator** | **Meaning** | **Example** | **Result** |
| --- | --- | --- | --- |
| `===` | Strict equality | `5 === 5` | `true` |
| `!==` | Strict inequality | `5 !== 3` | `true` |
| `==` | Loose equality | `5 == "5"` | `true` |
| `!=` | Loose inequality | `5 != "3"` | `true` |
| `>` | Greater than | `10 > 5` | `true` |
| `<` | Greater than | `5 < 10` | `true` |
| `>=` | Greater than or equal to | `10 >= 10` | `true` |
| `<=` | Less than or equal to | `5 <= 10` | `true` |

### Strict Equality (`===`)

Strict equality checks whether two values have the same value and data type.

```jsx
console.log(5 === 5); // true
console.log(5 === "5"); // false
```

### Loose Equality (`==`)

Loose equality allows JavaScript to convert values before comparing them.

```jsx
console.log(5 == "5"); // true
```

### Strict Inequality (`!==`)

Checks whether two values are not strictly equal.

```jsx
console.log(5 != "5"); // true
```

### Best Practice

Prefer `===` and `!==` over `==` and `!=` in most situations.

Strict comparisons avoid unexpected results caused by automatic type conversion.

## Useful Mathematical Methods

JavaScript provides the built-in `Math` object, which contains methods for common mathematical operations.

### `Math.round()`

Rounds a number to the nearest integer.

```jsx
console.log(Math.round(4.4)); // 4
console.log(Math.round(4.7)); // 5
```

### `Math.floor()`

Rounds a number down to the nearest integer.

```jsx
console.log(Math.floor(4.9)); // 4
```

### `Math.ceil()`

Rounds a number up to the nearest integer.

```jsx
console.log(Math.ceil(4.1)); // 5
```

### `Math.random()`

Returns a pseudorandom number greater than or equal to `0` and less than `1`.

```jsx
console.log(Math.random());
```

Generate a random integer between 1 and 10:

```jsx
let randomNumber = Math.floor(Math.random() * 10) + 1;

console.log(randomNumber);
```

Explanation:

1. `Math.random()` generates a value from 0 (inclusive) to 1 (exclusive).
2. Multiplying by `10` produces a value from 0 to less than 10.
3. `Math.floor()` rounds it down to an integer from 0 to 9.
4. Adding `1` produces an integer from 1 to 10.

## Practical Example: Calculating a Percentage

```jsx
const max = 57;

const actual = max - 13;

const percentage = actual / max;

console.log(max); // 57
console.log(actual); // 44
console.log(percentage); // 0.7719298245614035
```

The percentage can be converted into a more readable value:

```jsx
console.log((percentage * 100).toFixed(2) + "%"); // 77.19%
```

Here:

- `max` stores the maximum possible value.
- `actual` stores the calculated value.
- `percentage` stores the ratio between the actual and maximum values.
- `.toFixed(2)` formats the result to two decimal places and returns a string.
